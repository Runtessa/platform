# Community conduct

Runtessa welcomes contributors regardless of background or experience. Be respectful,
give actionable feedback, and distinguish technical disagreement from personal criticism.

Harassment, discriminatory language, sexualized attention, threats, impersonation
and sharing another person's private information are unacceptable in issues, pull
requests, reviews and project spaces.

Maintainers may remove content, close conversations or restrict participation to
protect the community. They should explain moderation decisions when doing so does
not reveal private information. Maintainers follow the same standards.

For a sensitive report, contact the maintainer through
[the GitHub profile](https://github.com/AlirezaDadrass) to establish a private channel;
do not publish the report or private details in a public issue. This project currently
has no separate moderation team or guaranteed response time.
